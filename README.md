## 👋 About me

I'm **Elijah**, from France. I build tools for **FiveM** (mostly Lua), administer roleplay servers, and write Python and JS for bots and websites.

Right now I'm focused on two projects:

- ☢️ **Nuclear Anticheat**: a commercial anticheat for FiveM
- 📦 **DigZip**: an open source extraction tool in C++

I work in small versions. Every version ships one real feature, and it gets tested before the next one starts.
