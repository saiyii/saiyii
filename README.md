## 👋 About me

I'm Elijah. I build things for **FiveM** (mostly Lua), run roleplay servers, and write Python and JS for bots and websites.

Right now my focus is on two projects: a commercial **anticheat for FiveM** and an **open source extraction tool in C++**. I work in small versions, and every one has to ship a real feature that actually gets tested.
